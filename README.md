# Yshelf

An immersive 3D interactive museum library website featuring a curved architectural gallery corridor, wall-mounted geometric designer bookshelves, realistic 3D books with pop-out interactions, and clear author plaques.

## 🚀 Technologies
- **Framework**: Next.js 14 (App Router) + React 18 + TypeScript
- **3D Engine**: Three.js + React Three Fiber (`@react-three/fiber`) + `@react-three/drei`
- **Animations**: GSAP + ScrollTrigger
- **Smooth Scroll**: `@studio-freight/lenis`
- **Styling**: Tailwind CSS

## ✨ Features
- **3D Curved Gallery Corridor**: Smooth camera glide along a CatmullRom spline path driven by user scroll.
- **Handcrafted Antique Museum Bookcases**: Classical fluted pilasters, arched pediments, 22-piece dentil moldings, and antique brass gooseneck picture lamps.
- **Razor-Sharp Brass Author Plaques**: High-contrast, unblurred 4K engraved museum brass nameplates with deep enamel lettering.
- **Realistic 3D Books**: Authentic curved spine geometry, 5 raised horizontal bands, gilded top page edges, hardcover board overhangs, and silk bookmark ribbons.
- **Interactive 3D Pop-Out & Inspection**: Hover over any volume for a 3D pop-out with metadata tooltips; click a shelf for centered camera inspection framing; click a book to view the detailed literary synopsis modal.

## 🛠️ Getting Started

First, install dependencies:
```bash
npm install --legacy-peer-deps
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience the 3D library corridor.
